VOBISS ERP - ALL REQUEST FORMS IN THE SYSTEM
===========================================

This is the complete list of request forms and request-style workflows currently present in the system.

1) MATERIAL REQUEST FORMS
   Main page:
   - src/pages/RequestForms.tsx
   Backend API:
   - backend/routes/requests.js
   DB logic:
   - backend/db.js
   Purpose:
   - Staff submit material requests for items needed for projects, operations, or site work.
   Status flow:
   - pending, approved, completed, rejected

2) ITEM RETURN REQUESTS
   Main page:
   - src/pages/ItemReturns.tsx
   Backend API:
   - backend/routes/requests.js
   DB logic:
   - backend/db.js
   Purpose:
   - Return inventory items that were previously issued or assigned.
   Status flow:
   - pending, approved, completed, rejected

3) CASH REQUEST FORMS
   Main page:
   - src/pages/finance/CashRequestForm.tsx
   Detail page:
   - src/pages/finance/CashDetails.tsx
   Backend API:
   - backend/routes/finance.js
   Shared request route:
   - backend/routes/requests.js
   Purpose:
   - Request cash advance or expense funds with supporting purpose and approvers.
   Status flow:
   - pending, approved, completed, rejected

4) TRANSPORT REQUEST FORMS
   Main page:
   - src/pages/transport/TransportRequestForm.tsx
   Detail page:
   - src/pages/transport/TransportDetail.tsx
   Approval page:
   - src/pages/transport/TransportApprovals.tsx
   Backend route:
   - backend/server.js
   Purpose:
   - Request transport support for trips, field operations, logistics, and work movement.
   Status flow:
   - pending, approved, rejected, completed

5) FUEL REQUEST FORMS
   Main page:
   - src/pages/transport/FuelRequestFormPage.tsx
   List page:
   - src/pages/transport/FuelRequestsListPage.tsx
   Detail page:
   - src/pages/transport/FuelRequestDetailPage.tsx
   Purpose:
   - Request fuel for vehicles and related operational travel.
   Status flow:
   - pending, approved, completed, rejected

6) RENTAL VEHICLE REQUEST FORMS
   Main page:
   - src/pages/transport/NewRentalVehicleRequestPage.tsx
   List page:
   - src/pages/transport/RentalVehicleRequestsPage.tsx
   Detail page:
   - src/pages/transport/VehicleRentalRequestDetailPage.tsx
   Backend route:
   - backend/routes/vehicle_requests.js
   Purpose:
   - Request rented vehicle support and linked transport work.
   Status flow:
   - draft, submitted, pending_manager, pending_finance, approved, cash_issued, rejected

7) CIRCUIT REQUEST FORMS
   Main page:

   Purpose:

8) PROJECT / SERVICE REQUEST FORMS

9) SIGN-OFF FORMS
   Main page:
   - src/pages/production/SignoffForms.tsx
   Purpose:
   - Sign off completed production or project work with approval/rejection flow.

10) LEAVE REQUEST FORMS
    Staff self-service leave:
    - src/pages/hr-self/Leave.tsx
    - src/components/hr/Leave/LeaveRequestForm.tsx
    - src/api/leave.ts
    Backend:
    - backend/routes/hrSelfLeave.js
    - backend/routes/hrLeave.js
    Core logic:
    - backend/services/leave.js
    - backend/db/hr.js
    Purpose:
    - Employee submits annual, sick, emergency, and other leave requests.
    Approval flow:
    - reliever -> supervisor -> manager -> CTO/HR approval stages
    PDF generation:
    - backend/utils/leavePdf.js
    - backend/utils/leaveHtml.js
    - src/api/leave.ts -> downloadLeavePdf()

11) OTHER REQUEST-STYLE WORKFLOW FORMS
    - src/pages/RequestDetails.tsx

    - src/pages/PendingApprovals.tsx

    - src/pages/ApprovedForms.tsx

    - src/pages/ItemsOut.tsx

MAIN FORM FAMILY SUMMARY
------------------------
The system currently uses these major request categories:

- Material Request
- Item Return
- Cash Request
- Transport Request
- Fuel Request
- Rental Vehicle Request
- Circuit Request
- Project / Service Request
- Sign-off Form
- Leave Request

ALL request forms are built around the same general pattern:
- user fills a form
- approver IDs are selected
- the request is submitted to the unified request API
- the record is stored in the database
- approvers review it
- it is approved, rejected, or finalized
- the detail page shows the final record and related history
- some records also have printable or downloadable PDF versions
